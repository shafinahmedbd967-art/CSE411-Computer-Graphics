## 🎯 Overview

This repository is **not a coding project** — it is a structured collection of everything I studied, submitted, and prepared throughout the semester for **CSE411: Computer Graphics**, the theory counterpart to the hands-on lab course (CSE412). While CSE412 focused on implementing algorithms in OpenGL, CSE411 covers the underlying mathematics, concepts, and theory behind computer graphics — so this repository holds assignments, midterm/final exam materials, past question papers with solutions, and the official course outline, all organized in one place for easy review and future reference.

---

## 📚 Course Overview

**CSE411 — Computer Graphics** covers the theoretical foundations behind how images, scenes, and animations are generated and manipulated by computers — the concepts that CSE412's lab work puts into practice.

Key areas typically covered in this course include:

- Fundamentals of computer graphics and display systems
- Line, circle, and curve generating algorithms (DDA, Bresenham's, Midpoint Circle)
- 2D and 3D geometric transformations
- Viewing and projection concepts
- Clipping algorithms
- Color models and rendering concepts
- Basics of animation and visualization theory
